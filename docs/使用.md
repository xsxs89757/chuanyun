# 怎么用

## 装好之后

打开穿云，输入管理员发给你的凭证，点登录。

如果装的是公司内部版，服务器地址和证书指纹已经在里面了，你只需要填凭证。

**第一次打开被系统拦住**：这个应用没有购买代码签名证书（一年几百刀，内部工具不值当）。

- macOS：右键点图标 → 打开 → 再点「打开」。直接双击会被拦。
- Windows：SmartScreen 提示时点「更多信息」→「仍要运行」。

每台机器做一次就好。

## 开一条隧道

假设你本地跑着一个服务，端口 8082。

点「新建隧道」，名字填 `wx`，端口填 `8082`。几秒后你会拿到：

```
https://你的名字-wx.t.公司域名
```

这个地址**固定不变**，重启客户端、重启电脑都是它。可以放心填进微信后台。

外面访问这个地址，请求就会到你本机的 8082。

## 调微信回调

1. 本地把服务跑起来
2. 开一条隧道指向它
3. 把隧道地址填进微信后台的回调 URL
4. 打断点，触发回调

回调直接打到你本机，可以单步调试。地址固定，明天再来不用重新填。

## 项目怎么接

### 一次性的：界面上建

适合个人的、临时的隧道。

### 团队项目：写进配置文件

在项目根目录放一个 `chuanyun.toml`，提交到 git，团队共享：

```toml
project = "crm"

[[tunnels]]
name = "api"
port = 8082

[[tunnels]]
name = "admin"
port = 5173
```

以后加端口就是加几行，同事拉下来重新导入即可。

### 脚本自动接入

穿云在本机 `127.0.0.1:7075` 提供了 HTTP 接口。启动脚本里加一行，端口就自动接上了：

```bash
curl -s -X POST localhost:7075/api/tunnels \
     -d '[{"port":8082,"name":"api"},{"port":5666,"name":"web"}]'
```

按名字幂等——脚本重复跑不会开出一堆重复隧道。

### 让回调地址跟着环境走

这是最省心的用法。业务代码里别写死地址，问穿云要：

```bash
# 隧道开着 → 公网地址；没开 → http://127.0.0.1:8082
curl -s 'localhost:7075/api/resolve?port=8082&plain=1'
```

放进环境变量，业务代码一个字都不用改：

```bash
export WX_CALLBACK_BASE=$(curl -s 'localhost:7075/api/resolve?port=8082&plain=1')
npm run dev
```

穿云没开着的时候这条命令会失败，脚本里可以兜一下：

```bash
BASE=$(curl -sf 'localhost:7075/api/resolve?port=8082&plain=1' || echo "http://127.0.0.1:8082")
```

## 本地接口一览

| 接口 | 作用 |
|---|---|
| `GET /api/status` | 连上没有、域名后缀是什么 |
| `GET /api/tunnels` | 当前所有隧道 |
| `POST /api/tunnels` | 注册隧道，接受单个对象或数组 |
| `DELETE /api/tunnels/{名字}` | 注销 |
| `GET /api/resolve?port=N` | 这个端口现在对外的地址，加 `&plain=1` 返回纯文本 |

只监听回环，并且会拒绝浏览器发来的请求（防的是恶意网页偷偷访问你的本地服务）。所以这些接口只能从命令行和脚本调，不能在网页里 fetch。

## 常见问题

**地址打开显示「没有正在运行的隧道」**

隧道没开着，或者地址拼错了。看一眼客户端里那条隧道的开关。

**隧道开着，但访问报「隧道那头没有响应」**

本地服务没起来，或者端口填错了。客户端会在那条隧道下面显示具体原因。

**前端 dev server 说 "Blocked request: this host is not allowed"**

Vite 默认只允许 localhost 访问。在 `vite.config.ts` 里放行隧道域名：

```ts
server: { allowedHosts: ['.t.公司域名'] }
```

**电脑合盖再打开，隧道还在吗**

在。客户端会自己重连，隧道也会自动恢复，地址不变。

**关掉窗口是不是就断了**

不是。关窗口只是收进托盘，隧道继续开着。真要退出走托盘菜单里的「退出」。

**配置文件在哪**

```bash
chuanyun --print-state-path
```

## 注意

隧道地址是**公网可达**的。开着的时候，任何知道地址的人都能访问到你本机的那个端口。

- 别把连着生产数据库的服务开出去
- 演示完随手关掉
- 不确定的时候，关掉比开着好
