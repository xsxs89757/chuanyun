# 部署服务端

一次性的事，做完之后同事装上客户端就能用。

## 你需要准备

- 一台有公网 IP 的服务器（现有的就行，不用新开）
- 一个**已备案**的域名，能加一条泛解析记录
- 该域名的泛域名证书（微信回调要求 HTTPS）

关于备案：微信公众号、小程序、支付的回调地址都要求备案域名。如果你的域名已经在用了，那就已经满足。

## 一、域名解析

给隧道单独开一个子域，比如 `t.example.com`，加一条泛解析：

```
*.t.example.com   A   你的服务器IP
```

**建议用独立子域而不是主域**：隧道地址和生产站点分开，出问题不互相牵连，Cookie 也不会串。

## 二、装服务端

```bash
# 下载并放到 /usr/local/bin
sudo install chuanyun-server /usr/local/bin/

# 配置
sudo mkdir -p /etc/chuanyun /var/lib/chuanyun
sudo tee /etc/chuanyun/server.toml > /dev/null <<'EOF'
[http]
domain_suffix = "t.example.com"

[storage]
data_dir = "/var/lib/chuanyun"
EOF
```

配置只有这两项是必填的，其余都有合理默认值：控制通道 `0.0.0.0:7000`、HTTP 入口 `127.0.0.1:7080`、管理接口 `127.0.0.1:7001`。

装成系统服务：

```bash
sudo useradd -r -s /usr/sbin/nologin chuanyun
sudo chown -R chuanyun:chuanyun /var/lib/chuanyun
sudo install deploy/chuanyun-server.service /etc/systemd/system/
sudo systemctl enable --now chuanyun-server
```

第一次启动会自签一张证书并把**指纹**打印到日志里。记下它：

```bash
sudo journalctl -u chuanyun-server | grep 指纹
```

## 三、接进 nginx

服务端只监听内网明文 HTTP，443 和证书仍然归 nginx 管——不用抢端口，证书续期也沿用你现在的流程。

把 [`deploy/nginx.conf.example`](../deploy/nginx.conf.example) 改改用（替换域名和证书路径）。四个要点：

| 配置 | 为什么 |
|---|---|
| `proxy_set_header Host $host` | 子域名路由完全靠原始 Host，不透传就找不到隧道 |
| `Upgrade` / `Connection` 头 | WebSocket 要用 |
| `proxy_buffering off` | 否则 SSE 不实时、大响应会先落盘 |
| `client_max_body_size 200m` | 大文件上传 |

**宝塔面板**：把配置放进 `/www/server/panel/vhost/nginx/` 下的独立 conf，别直接改面板生成的站点配置——面板重写时会覆盖掉。

## 四、放行端口

除了 nginx 用的 80/443，还要放行**控制通道**（默认 7000）——客户端出站连它，这条连接自带 TLS，不经过 nginx。

```bash
# 云服务器还要在安全组里同样放行
sudo ufw allow 7000/tcp
```

## 五、发凭证

```bash
sudo -u chuanyun chuanyun-server user add zhangsan
```

输出的凭证**只显示这一次**——库里只存哈希，丢了只能重新签发。把它连同证书指纹一起发给本人。

其他管理命令：

```bash
chuanyun-server user list           # 谁有凭证、有没有过期
chuanyun-server user revoke zhangsan # 吊销（在线连接会立刻断开）
chuanyun-server kick zhangsan        # 只踢下线，凭证还有效
chuanyun-server status               # 现在几个人在线、几条隧道
```

## 六、验证

让同事装上客户端、输入凭证、开一条隧道，然后从外网访问那个地址。

顺利的话就到此为止了。不顺利的话看下面。

## 排查

**客户端连不上**

- 控制通道端口放行了吗（`nc -vz 服务器 7000`）
- 指纹填对了吗——填错会明确提示「证书指纹不符」
- 服务端起来了吗（`systemctl status chuanyun-server`）

**隧道地址打开是 404 品牌页**

说明请求到了服务端但没找到隧道。检查客户端那边隧道是不是开着，以及 nginx 有没有透传 Host 头。

**隧道地址打不开 / 证书报错**

先确认泛解析生效（`dig zhangsan-test.t.example.com`），再确认泛域名证书覆盖了这一级子域。

**微信提示回调地址不合法**

微信填的是具体子域名，不接受通配符。把客户端里显示的完整地址原样贴进去。域名必须已备案。

**老安卓或微信内打不开，浏览器却正常**

多半是证书链的问题。Let's Encrypt 新根在部分老设备上不被信任，签发时选完整链，或者换一家的免费证书。

## 给同事的下载页

服务端自带一个下载页，把安装包放进去就能用：

```bash
# 管理接口只监听回环，用 nginx 反代一个内网可达的路径
# location /chuanyun/ { proxy_pass http://127.0.0.1:7001/; }
```

页面上已经写好了「第一次打开要右键」这类说明。
